# ImQMD 代码实现捷径审计报告

**生成日期**: 2026-06-27  
**审计依据**: `papers/imqmd_model_spec.md` (1026 行论文规范) + `papers/spec_vs_code_audit.md` (前期差距分析)  
**审计代码**: `mnt_sim/imqmd/` 全部 7 个 Python 文件  
**审计方法**: 逐函数对比代码实现与论文规范方法，识别所有「以简化/廉价方法替代论文标准方法」的捷径

---

## 捷径分类体系

| 分类 | 代码 | 定义 |
|------|------|------|
| **S-采样** | S-SAMP | 质心采样替代网格/体积积分 |
| **F-公式** | F-APPROX | 简化/近似公式替代论文精确公式 |
| **A-算法** | A-SIMP | 简化算法流程，跳过论文关键步骤 |
| **H-硬编码** | H-CODE | 硬编码数值替代论文参数化/自洽计算 |
| **M-缺失** | M-MISS | 论文要求但代码完全缺失的功能道/机制 |

严重度评级:
- **致命**: 直接改变物理结果，使计算结果与论文不可比
- **严重**: 显著影响定量结果，在特定条件下可能有定性差异  
- **中等**: 影响定量精度，但定性行为可接受
- **轻微**: 边缘影响，或在特定场景下才体现

修复难度:
- **高**: 需要重构核心算法，>2 天工作量
- **中**: 需要修改关键函数，0.5-2 天
- **低**: 参数/配置修改，<0.5 天

## S-采样类：质心采样捷径 (Centroid Sampling)

### S-1. 体积能量密度 → 质心点采样
- **位置**: `skyrme.py:skyrme_potential()` (line 68-76), `symmetry_energy()` (line 112-120)
- **论文要求**: W2014-5 为能量密度在空间的体积积分 `U_loc = ∫ V_loc(r) d³r`
- **代码实现**: 仅在核子质心位置 `r_i` 评估被积函数并求和 `Σ V_loc(r_i)`，等效于被积函数在质心点的离散采样
- **根本差异**: 
  - 论文: `∫ f(ρ(r)) d³r` — 连续空间积分
  - 代码: `Σ f(ρ(r_i))` — 质心点离散求和
  - 缺失了核间区域的贡献，可能低估体积效应
- **影响**: 严重。对于表面弥散的核子分布，体积分与质心采样的差异可达 5-15%
- **难度**: 高。需要实现空间网格上的密度重建和数值积分
- **优先级**: P1（影响所有 EDF 项的计算精度）

### S-2. 库仑交换能 → 质心采样
- **位置**: `skyrme.py:coulomb_exchange_energy()` (line 96-110)
- **论文要求**: Zhao2016-2: `-(3/4)e²(3/π)^(1/3) ∫ ρ_p(R)^(4/3) d³R` — 空间体积积分
- **代码实现**: 在质心位置计算 `ρ_p(r_i)^(4/3)` 并求和 `Σ`，除以 `ρ₀`
- **根本差异**:
  - 论文: Slater 交换项的体积分 `∫ ρ_p^(4/3) d³R`
  - 代码: 质心点采样 `Σ ρ_p^(4/3) / ρ₀`，多了一个除以 `ρ₀` 的因子
  - 除以 `ρ₀` 的来源不明，不是 Zhao2016-2 的标准形式
- **影响**: 严重。除以 `ρ₀≈0.165` 相当于将交换能放大 ~6 倍，且质心采样改变了积分结构
- **难度**: 中。需去除 `ρ₀` 分母并实现网格积分
- **优先级**: P1

### S-3. 所有力的计算 → 质心梯度解析
- **位置**: `propagator.py:_centroid_density_force()` (line 65-103), `_coulomb_exchange_force()` (line 37-62)
- **论文要求**: 力为 EDF 的体积积分对质心坐标的梯度 `F_i = -∂/∂r_i ∫ V_loc d³r`
- **代码实现**: 对质心采样的能量做解析微分，得到 `∂(Σ f(ρ(r_j)))/∂r_i`
- **根本差异**: 
  - 论文: 先积分再微分（连续）
  - 代码: 先采样再微分（离散），自洽但略过积分步骤
  - 力的公式形式上自洽于质心采样能量，但对于 (∇ρ)² 等梯度项，力更加偏离
- **影响**: 中等。在质心采样自洽框架下力是精确的导数，但与论文的连续框架有系统性偏差
- **难度**: 高。需与 S-1 一起重构
- **优先级**: P1（跟随 S-1 修复）

## F-公式类：简化/近似公式 (Formula Approximation)

### F-1. 表面项：有限力程高斯凝聚 → 替代 (∇ρ)²
- **位置**: `skyrme.py:surface_pair_energy()` (line 122-141), `propagator.py:_surface_pair_force()` (line 106-115)
- **论文要求**: W2014-5 同位旋标量表面项 `g_sur/(2ρ₀)·(∇ρ)²` — 密度梯度的平方
- **代码实现**: `-gsur/7 · Σ_{i<j} exp(-r_ij²/4σ_r²)` — 核子对之间的高斯权重凝聚
- **根本差异**:
  - 论文: 基于连续密度场的梯度，产生排斥性表面张力
  - 代码: 基于离散粒子对距离的吸引性高斯势，用 `/7` 缩放强度
  - 两者物理机制完全不同: (∇ρ)² 在密度梯度大的表面区域为正，而高斯凝聚在所有核子对间为负（吸引）
  - `/7` 因子为经验调节，无理论依据
- **影响**: 致命。这是**最严重的捷径之一**。表面项改变了能量泛函的定性结构：论文的 (∇ρ)² 是排斥性表面张力，代码的高斯凝聚是吸引性。在表面丰富的核反应中会产生定性不同的结果。
- **难度**: 高。需要 (1) 在网格上计算密度梯度 ∇ρ(r)，(2) 实现 (∇ρ)² 的体积分，(3) 推导并实现对应的梯度力
- **优先级**: P0（最高优先级，改变物理本质）

### F-2. 表面对称能项：有限力程 → 替代 κ_s(∇ρ)²δ²
- **位置**: `skyrme.py:surface_symmetry_energy()` (line 143-154), `propagator.py:_surface_symmetry_pair_force()` (line 118-129)
- **论文要求**: W2014-5: `C_s/(2ρ₀)·[-κ_s(∇ρ)²]δ²` — 密度梯度和同位旋不对称度的耦合
- **代码实现**: `-C_s·κ_s/7 · Σ_{i<j} exp(-r_ij²/4σ_r²)·τ_i·τ_j`，其中 `τ_i = -1` (质子) / `+1` (中子)
- **根本差异**:
  - 论文: δ² = ((ρ_n-ρ_p)/ρ)² 是局域量
  - 代码: τ_i·τ_j 是全局同位旋标记的配对乘积，不对应 δ²
  - 同 F-1，`/7` 缩放无理论依据，且缺少密度梯度的参与
- **影响**: 致命。κ_s 是 IQ3a/IQ3b 参数集区别于 IQ1/IQ2/IQ3 的关键参数（IQ3a: κ_s=0.4, IQ3b: κ_s=0.6），错误的实现使这些参数集失去物理意义。
- **难度**: 高。需连同 F-1 一起重构
- **优先级**: P0

### F-3. 表面项强度缩放 `/7`
- **位置**: `skyrme.py` line 140, 153; `propagator.py` line 114, 128
- **论文要求**: 无此因子
- **代码实现**: 表面能和表面力中 `gsur /= 7` 和 `C_s·κ_s /= 7`
- **根本差异**: 对高斯凝聚模型的经验缩放，使强度值与 Δr=3 fm 的高斯力程和核子数匹配
- **影响**: 严重。因子 `/7` 是纯经验的，对不同的核子数 A 不具有普适标度关系
- **难度**: 低（替换为正确的 (∇ρ)² 公式后自然消失）
- **优先级**: P0（随 F-1/F-2 自动解决）

### F-4. Weisskopf 蒸发 → 极简中子蒸发模型
- **位置**: `decay.py:weisskopf_evaporation()` (line 136-179)
- **论文要求**: Weisskopf-Ewing 积分 `Γ_j ∝ ∫₀^{E*-B_j} σ_j^inv(ε)·ρ_d(E*-B_j-ε)·ε dε`
- **代码实现**: 使用 `exp(-cumulative_cost/T)·phase·window` 的经验权重公式，其中
  - `phase = (E_rem/E_star)^(0.5*a)` 为相空间因子简化
  - `window = (E_star/cumulative_cost)^n` 为连续发射窗口因子
  - `a = A/8.0` 为简化能级密度参数
- **根本差异**:
  - 论文: 逆截面积分 + 子核能级密度积分，涉及具体核的 B_j、σ_j^inv(ε)、ρ_d
  - 代码: 三个纯经验因子乘积，无积分、无逆截面、无能级密度
- **影响**: 致命。蒸发概率的量级和相对分支比与标准 Weisskopf-Ewing 不可比；且完全缺失 p、α 蒸发道和 γ 冷却
- **难度**: 高。需要完整实现 Weisskopf-Ewing 框架
- **优先级**: P1

### F-5. 裂变竞争 → 简化 Boltzmann 因子
- **位置**: `decay.py:fission_competition()` (line 118-133)
- **论文要求**: Bohr-Wheeler 积分 `Γ_f ∝ 1/(2πρ_p(E*))·∫₀^{E*-B_f} ρ_s(E*-B_f-ε) dε`
- **代码实现**: `exp(-B_f/T) / (exp(-B_f/T) + 1)`，其中 `T = √(E*/a)`, `a = A/8`
- **根本差异**:
  - 论文: 对鞍点态密度的积分，包含 ρ_p(E*) 分母
  - 代码: 简化 Boltzmann 概率 + 对 Z≥100/104 的任意放大因子 (×8, ×20)
- **影响**: 严重。简化的指数形式仅在高温极限下近似 Bohr-Wheeler，且手动放大因子无理论依据
- **难度**: 中。可以实现完整的鞍点积分框架
- **优先级**: P2

### F-6. 裂变位垒 → 经验液滴公式
- **位置**: `decay.py:fission_barrier()` (line 102-115)
- **论文要求**: 论文使用外部代码（HIVAP）的内置位垒，未指定具体公式
- **代码实现**: `B_f = 21.0·(1 - Z²/(47A))²` + 对 Z≥92/100 的缩放因子 (×0.65, ×0.35)
- **根本差异**: 液滴模型位垒 + 手动缩放 vs HIVAP 的宏观-微观位垒（含壳修正）
- **影响**: 严重。HIVAP 的位垒含壳效应，对超铀核的裂变分支比影响巨大
- **难度**: 中。需要引入实验或宏观-微观位垒表
- **优先级**: P2

### F-7. 光复合粒子凝聚 → 简化相空间凝聚
- **位置**: `fragments.py:coalescence_light()` (line 191-243)
- **论文要求**: Wei 2014 表面凝聚模型: 核心半径 R₀、表面厚度 D₀、领头核子、Jacobi 相空间条件 R_im·P_im ≤ h₀、Coulomb 位垒穿透、能标依赖的 h₀
- **代码实现**: 简单的近邻相空间凝聚: `|Δr| ≤ r_cut=2.4`, `|Δp| ≤ p_cut=180`，贪婪匹配
- **根本差异**:
  - 论文: 基于表面穿透机制，有明确的物理参数 (R₀~1.4A^(1/3), D₀=2.3 fm, h₀=200/260/330)
  - 代码: 通用相空间截断，无表面物理、无 Coulomb 位垒检查、无能标依赖
- **影响**: 严重。对于中能散裂反应（Wei 2014 的目标场景），表面凝聚的 LCP 产额与简单相空间凝聚有显著差异
- **难度**: 高。需要实现完整的表面穿透+位垒检查+Jacobi 坐标框架
- **优先级**: P2

### F-8. PB(W*) 改进 Pauli 阻塞 → 仅宽度放大
- **位置**: `collisions.py:pauli_blocking_probability_v2()` (line 129-148)
- **论文要求**: Chen 2024 Eqs.(6,7): 对每个核子 j 生成 N 个动量样本 `P_{j,λ}`，计算平均占位数 `c_j(p') = (1/N)Σ_λ exp[-(p'-P_{j,λ})²/2σ_p²]`
- **代码实现**: 仅将 Wigner 核的 `σ_r` 放大 1.35 倍 (`width_scale=1.35`)，对应的 `σ_p` 自动缩小（因 `σ_r·σ_p=ħ/2`），不做多态采样
- **根本差异**:
  - 论文 PB(W*): 通过多态采样减少统计涨落，Chen 2024 报告方差降低 ~70%
  - 代码 "v2": 仅是一个更宽的单一 Wigner 核，不改变采样策略，方差降低效果远小于文献报告
- **影响**: 严重。错误的 PB(W*) 实现可能导致低估/高估 Pauli 阻塞概率，影响碰撞率和能量耗散
- **难度**: 中。需要在每次碰撞尝试时为周围核子生成多组动量样本
- **优先级**: P1

## A-算法类：算法简化 (Algorithm Simplification)

### A-1. 初始化：简单硬球 → 代替中子皮+费米动量修正
- **位置**: `initializer.py:initialize_nucleus()` (line 78-142)
- **论文要求**: Wang 2014 Sec. II.B 完整链:
  1. `R_c = 1.226A^(1/3) + 2.86A^(-2/3) - 1.09(I-I²) + 0.99ΔE/A` (W2014-8)
  2. `ΔR_np = 0.9I - 0.03` (W2014-9)
  3. `R_p = √(5/3)·√(⟨r_c²⟩ - 0.64)`, `R_n = √(5/3)·(⟨r_p²⟩^(1/2)+ΔR_np)` (init-rp, init-rn)
  4. 在 `R_p - 0.8` 和 `R_n - 0.8` 半径内分别采样 p/n 位置
  5. `p_F,q(r_i) = ħ[3π²ρ_q(r_i)]^(1/3) - w_p` (init-pf)
- **代码实现**:
  1. `radius = 1.14·A^(1/3)` — 单一硬球半径，p/n 无区分
  2. 无中子皮修正
  3. p/n 位置混洗后统一采样
  4. 无 `w_r = 0.8` fm 波包宽度修正
  5. `p_F = ħ[3π²ρ_q]^(1/3)` 后乘 scale (0.50-0.70) — 无 `w_p` 自洽减去
- **影响**: 致命。初始化决定了所有后续计算的起点。缺失中子皮修正导致丰中子核的中子分布过紧，缺失 w_r 导致初始密度偏高，缺失 w_p 导致费米面系统偏移。这些误差在千 fm/c 演化中累积放大。
- **难度**: 高。需实现完整的中子皮初始化链
- **优先级**: P0

### A-2. 相空间截断：170 → 255 fm·MeV/c
- **位置**: `initializer.py` line 100
- **论文要求**: init-phase: `|Δr||Δp| ≥ 255 fm·MeV/c`
- **代码实现**: `phase_space_threshold = 170.0` — 低 33%
- **影响**: 致命。170 的截断允许更紧密的初始相空间堆积，导致过高估计初始密度和过低估计初始动量分散。这将系统性地影响基态结合能和后续动力学。
- **难度**: 低。改即可，但需验证在 255 下初始化成功率
- **优先级**: P0

### A-3. 初始化演化时间：50 fm/c → 600 fm/c
- **位置**: `initializer.py` line 123-133
- **论文要求**: 至少 600 fm/c 无阻尼自由演化，检查结合能漂移和粒子发射
- **代码实现**: 仅 50 步 × 1 fm/c = 50 fm/c，且每步施加动量阻尼 (×0.93)
- **根本差异**:
  - 50 fm/c 不足以让初始化伪影消散（典型弛豫时间 ~200-300 fm/c）
  - 阻尼人为压制了不稳定模式，使初始化看起来比实际更稳定
- **影响**: 致命。阻尼掩盖了初始化质量不足的问题；50 fm/c 不足以检测慢漂移模式
- **难度**: 中。需要实现更长演化+移除阻尼+添加稳定性诊断
- **优先级**: P0

### A-4. 动量阻尼：非物理的速度衰减
- **位置**: `initializer.py` line 133, 180; `initializer.py` line 167
- **论文要求**: 无阻尼的哈密顿演化，通过 Pauli/CoMD 约束维持相空间
- **代码实现**: `momenta *= 0.93` — 每步动量缩小 7%
- **影响**: 严重。动量阻尼是非物理的冷却机制，人为压制激发模式，使能量看起来更守恒。在移除阻尼后，当前初始化可能无法通过稳定性检验。
- **难度**: 低。移除 `damping=0.93` 即可，但需验证无阻尼稳定性
- **优先级**: P0（随 A-3 一起解决）

### A-5. 能量校准：energy_offset 打补丁 → 代替严格 BE 筛选
- **位置**: `initializer.py` line 139-141
- **论文要求**: init-energy: `E_ground ∈ BE ± 0.05 MeV` 严格接受条件
- **代码实现**: 计算 `empirical_binding_per_nucleon()` 半经验结合能作为 target，将 `target - actual_total` 赋给 `energy_offset`，后续能量计算都加上这个常数偏移
- **根本差异**:
  - 论文: 拒绝不满足结合能的初始化，重新采样
  - 代码: 总能接受，用一个常数平移来强制满足结合能
  - `energy_offset` 是一个非物理的常数势场项，破坏了 EDF 的自洽性
- **影响**: 致命。`energy_offset` 使所有能量诊断（结合能、激发能、反应 Q 值）偏移，且对于不同核素偏移不同，破坏了可移植性。这本质上是「强行拟合」而非「自洽描述」。
- **难度**: 高。需要迭代初始化直至 EDF 自洽结合能落入接受窗口
- **优先级**: P0

### A-6. 静态参考场：非物理的简谐弹簧
- **位置**: `skyrme.py:static_mean_field_energy()` (line 161-167), `propagator.py:_static_reference_force()` (line 132-153)
- **论文要求**: 无此项。核子仅受 Skyrme EDF + Coulomb 力
- **代码实现**: `U_static = 0.5·k·Σ(r_i - r_ref)²` — 将核子拴在初始化位置的简谐弹簧
- **根本差异**: 纯粹的数值稳定技巧，无物理基础。`static_k=5.0 MeV/fm²` 为一个相当强的弹簧。
- **影响**: 严重。静态场压制了核子的真实动力学，使激发模式的人为衰减。任何依赖静态场的稳定性结论都不能外推到无弹簧的真实演化。
- **难度**: 低。移除或可选，但需确保无弹簧下稳定性
- **优先级**: P1

### A-7. MST 默认参数偏离论文标准值
- **位置**: `fragments.py:minimum_spanning_tree()` (line 82-102), `isospin_mst()` (line 105-127)
- **论文要求**:
  - 标准 MST: R₀=3.5 fm, P₀=250 MeV/c (Z2012-MST)
  - iso-MST: R_nn=6, R_np=6, R_pp=3 fm, P₀=250 MeV/c (iso-MST-R, iso-MST-P)
- **代码默认值**:
  - 标准 MST: `r_cut=3.0`, `p_cut=300.0`
  - iso-MST: `r_cut_pp=2.8, r_cut_nn=2.8, r_cut_np=3.2`, `p_cut=300.0`
- **根本差异**: 
  - R₀: 3.0 vs 3.5 (差 14%)
  - P₀: 300 vs 250 (差 20%)
  - iso-MST: nn/np 截断 2.8/3.2 vs 6.0/6.0 (差 ~100%)
- **影响**: 致命。iso-MST 的 nn/np 截断差异 2 倍以上，将完全改变中子-rich 碎片的识别结果。标准 MST 的偏差也会系统改变碎片多重数。
- **难度**: 低。改默认值即可，但需验证
- **优先级**: P0

### A-8. 费米面检查阈值：140 → 论文值未明确规定
- **位置**: `collisions.py:fermi_constraint_check()` (line 380)
- **论文要求**: CoMD 风格的相空间约束，阈值未在论文中显式给出
- **代码实现**: `threshold=140.0` — 低于初始化截断 170
- **影响**: 中等。传播中的约束比初始化更弱，可能导致相空间堆积
- **难度**: 低
- **优先级**: P2

### A-9. 推进中的刚性 CM 修正
- **位置**: `propagator.py:_rk4_step()` line 216-221
- **论文要求**: cm-correction 仅在初始化时做一次
- **代码实现**: 每步 RK4 后都执行 `positions -= mean(positions)`, `momenta -= mean(momenta)`
- **根本差异**: 论文的 CM 修正是初值修正；代码每步施加，等效于不断重置 CM 坐标和动量
- **影响**: 中等。对于单核演化，每一步都重置 CM 会微妙抑制全局运动模式并人为改善表观稳定性
- **难度**: 低
- **优先级**: P2

## H-硬编码类：硬编码参数 (Hardcoded Values)

- **位置**: `collisions.py` line 10: `RHO0 = 0.16`
- **论文要求**: 所有 IQ 参数集使用 `ρ₀ = 0.165 fm⁻³`
- **代码实现**: 碰撞模块的介质修正和密度相关计算使用硬编码的 `0.16` 而非参数集的 `0.165`
- **影响**: 严重。介质修正因子 `1-η·ρ/ρ₀` 中分母偏小 ~3%，系统性改变介质修正强度
- **难度**: 低。改为从 parameter set 的 `rho0` 读取
- **优先级**: P1

### H-2. 费米动量经验缩放 scale
- **位置**: `initializer.py` line 105: `scale = (0.70, 0.65, 0.60, 0.55, 0.50)[attempt % 5]`
- **论文要求**: 从 `p_F = ħ[3π²ρ_q]^(1/3)` 减去自洽确定的 `w_p`
- **代码实现**: 循环尝试 5 个经验缩放因子，取使相空间最小值最大的那个
- **根本差异**: 论文用物理量 w_p 系统修正，代码用纯经验 scale 扫描
- **影响**: 严重。经验 scale 对不同的核素不具有可移植性
- **难度**: 中。需要实现 w_p 自洽确定算法
- **优先级**: P0（随 A-1 一起解决）

### H-3. 半经验结合能公式参数
- **位置**: `initializer.py:empirical_binding_per_nucleon()` (line 64-75): `av=15.75, assym=17.8, ac=0.711, asym=23.7, ap=11.18`
- **论文要求**: 使用 Skyrme EDF 自身的基态结合能

### H-4. 能量漂移接受阈值 8%
- **位置**: `initializer.py` line 203: `drift <= 0.08`
- **论文要求**: 无明确百分比，但要求千 fm/c 稳定
- **代码实现**: 接受 500 fm/c 内 8% 的能量漂移
- **影响**: 中等。8% 的漂移对某些核素可能偏大（例如重核 1600 MeV 总能的 8% = 128 MeV）
- **难度**: 低
- **优先级**: P2

### H-5. Pauli 阻塞 floor 值

- **难度**: 低
- **优先级**: P2

### H-6. 邻居搜索网格参数

- **代码实现**: 经验参数，影响碰撞候选对的筛选效率
- **影响**: 轻微。仅影响性能，不影响物理
- **难度**: 低
- **优先级**: P3

### H-7. 宽度未根据 A 自动计算
- **位置**: `skyrme.py:PARAMETER_SETS` 存储了 σ₀, σ₁，但 `initializer.py` 接受固定的 `sigma_r=1.1`

- **难度**: 低。实现 `compute_sigma_r(A, params)` 并在初始化时调用
- **优先级**: P1

## M-缺失类：完全缺失的功能道/机制

### M-1. ImQMD05 动量相关相互作用 u_md
- **论文要求**: Z2012-5: 显式动量相关的 Yukawa 型相互作用 `u_md = C₀/(2ρ₀)·Σ∫∫ f_N1(p1)f_N2(p2)·1.57[ln(1+5×10⁻⁴(Δp)²)]² d³p1 d³p2`，以及修正的运动方程 `ṙ_i = p_i/m + ∂U_md/∂p_i`
- **代码状态**: 完全缺失。无法模拟中能 (~50-200 MeV/A) 重离子碰撞
- **影响**: 致命。对于中能应用，动量相关相互作用是必不可少的，缺失导致无法描述光学势、有效质量和核子发射能谱

- **影响**: 致命。无反应初始化意味着当前代码完全不能做任何反应计算
- **难度**: 高。需实现完整的双核 + 碰撞参数框架

## 关键提醒

1. **`energy_offset` 是系统性错误的根源**: 当前所有能量值（结合能、激发能、反应 Q 值）都包含了一个非物理常数平移。任何基于当前代码的定量结论在移除 offset 后都需要重新验证。

2. **表面项的有限力程替代是定性错误**: 论文的 (∇ρ)² 是排斥性表面张力，代码的高斯凝聚是吸引性。这不是近似精度的差异，而是物理机制的差异。对于表面丰富的反应过程（熔合、多碎片产生），这个差异可能导致定性相反的结论。

3. **阻尼+静态场掩盖了不稳定性**: 当前「稳定性验证」都是在有人为稳定机制（动量阻尼、静态弹簧、每步 CM 重置）下进行的。移除这些机制后，代码可能无法保持千 fm/c 稳定——这正是论文要求的真正的测试。

4. **iso-MST 参数是最容易修复的致命问题**: 将 `r_cut_nn` 和 `r_cut_np` 从 2.8 改为 6.0 只需改一行代码，但会彻底改变中子-rich 碎片的识别结果。在做此修改前，建议先评估对当前结果的影响。
