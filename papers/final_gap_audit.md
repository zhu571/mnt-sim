## 1. EDF 参数集

### 差距 1.1: 默认参数集使用 IQ2 而非 IQ3a

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★★★ Major |
| **修复难度** | ◆ 极低（改一行默认值） |
| **当前状态** | `SkyrmeEDF()` 默认使用 `PARAMETER_SETS["IQ2"]` |
| **论文要求** | Wang 2014 融合计算使用 IQ3a/IQ3b；Zhao 2016 U+U 使用 IQ3a；IQ2 主要用于 Zhao 2016 及 Zhang 2012 的中间能区 |
| **影响** | U+U 计算若使用错误的参数集将导致完全不同的状态方程行为；IQ2 的对称能斜率 ~58 MeV vs IQ3a 的 ~45 MeV，直接影响中子皮和 fusion |
| **修复方案** | 将 `SkyrmeEDF.__init__` 默认参数改为 `PARAMETER_SETS["IQ3a"]`，或要求调用方显式指定 |

### 差距 1.2: 缺少 SkP* 参数集

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★★ Moderate |
| **修复难度** | ◆ 极低（添加一行参数定义） |
| **当前状态** | `PARAMETER_SETS` 仅包含 IQ1/IQ2/IQ3/IQ3a/IQ3b |
| **论文要求** | Wang 2014 Table I 定义了 SkP*: α=-356, β=303, γ=7/6, g_sur=19.5, g_τ=13, η=2/3, C_s=35, κ_s=0.65, ρ0=0.162, σ0=0.94, σ1=0.018 |
| **影响** | 无法复现 Wang 2014 的 SkP* 对照计算 |
| **修复方案** | 在 `PARAMETER_SETS` 字典中添加 `"SKP*"` 条目 |

### 差距 1.3: 缺少 ImQMD05 显式动量相关相互作用

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★★ Major |
| **修复难度** | ◆◆◆◆ 极高（需重新实现整个 u_md 积分） |
| **当前状态** | EDF 仅包含 Wang 2014 Eq.(5) 的局域项，无 Zhang 2012 Eq.(5) 的动量相关项 |
| **论文要求** | ImQMD05 的完整 Hamiltonian 包含 u_md（Zhang 2012 Eq.5），影响中间能区的动力学 |
| **影响** | 对于 E_beam > 20 MeV/A 的重离子碰撞，缺少动量相关项会导致核子-核子碰撞动力学不正确 |
| **修复方案** | 实现 Zhang 2012 Eq.(5) 的 1.57*[ln(1+5e-4*(Δp)^2)]^2 动量相关能量密度及其梯度力 |

### 差距 1.4: 缺少 isovector 表面项 g_sur_iso

## 2. 初始化方法

### 差距 2.1: 硬球半径使用简化公式而非 Wang 2014 中子皮公式

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★★★★ Critical |
| **修复难度** | ◆◆ 中等 |
| **当前状态** | `initialize_nucleus()` 使用 `radius = 1.14*A^(1/3)` 单一硬球半径 |
| **论文要求** | Wang 2014 Sec.II.B: 需分别计算 R_p 和 R_n（通过电荷半径 R_c 和中子皮 ΔR_np），且质子和中子在不同硬球内采样 |
| **已有基础设施** | `_wang_skin_radii()` 和 `_sample_grid_positions()` 已正确实现 Wang 2014 公式——但 `initialize_nucleus()` 没有调用它们！ |
| **影响** | 富中子核的中子皮完全错误，直接影响 U+U 等重核计算的初始几何 |
| **修复方案** | 让 `initialize_nucleus()` 调用 `_sample_grid_positions()` 替代当前的简化采样 |

### 差距 2.2: 动量采样方法偏离论文 w_p 方案

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★★★★ Critical |
| **修复难度** | ◆◆ 中等 |
| **当前状态** | `_fermi_momenta()` 使用 scale 因子（0.70, 0.65, 0.60, 0.55, 0.50）乘以局部费米动量 |
| **论文要求** | Wang 2014: `p_{F,q}(r_i) = ħ[3π²ρ_q(r_i)]^(1/3) - w_p`，其中 w_p 是调谐参数使基态结合能正确 |
| **影响** | 动量分布形状不同：scale 因子是全局缩减，w_p 是固定截断；对于重核（A=476），差异累积导致结合能不匹配 |
| **修复方案** | 实现 `p_F - w_p` 采样，w_p 通过迭代调谐至 BE 收敛 |

### 差距 2.3: 没有 BE±0.05 MeV 接受标准——使用能量偏移强制匹配

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★★★★ Critical |
| **修复难度** | ◆◆◆ 较高 |
| **当前状态** | `initialize_nucleus()` 在弛豫后计算 `energy_offset = target_total - raw_components["total"]`，直接强行使总能等于目标值 |
| **论文要求** | Wang 2014: 只接受 `E_ground ∈ BE±0.05 MeV` 的核；不接受则重新采样 |
| **影响** | 这是最严重的差距。能量偏移掩盖了 Hamiltonian 与实验基态之间的不一致。U+U (A=476) 完全解体的根本原因之一——重核的能量偏移过大（可达 100+ MeV），但弛豫后去除弹簧时真实 Hamiltonian 无法维持结合 |
| **修复方案** | 移除 `energy_offset` 机制，改为：1) 使用正确的 w_p 调谐；2) 多次采样直到 BE 收敛在 0.05 MeV 以内；3) 弛豫至少 600 fm/c 后验证稳定性 |

### 差距 2.4: 相位空间距离阈值错误

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★★★ Major |
| **修复难度** | ◆ 极低（改一个常数） |
| **当前状态** | `initialize_nucleus()` 使用 `phase_space_threshold = 170.0` |
| **论文要求** | Wang 2014: `|r_i-r_j|*|p_i-p_j| ≥ 255 fm·MeV/c` |
| **影响** | 阈值过低导致初始配置接受了一些相位空间过近的核子对，可能导致体系在弛豫初期不稳定 |
| **修复方案** | 将 `phase_space_threshold` 改为 255.0 |

### 差距 2.5: 弛豫时间严重不足

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★★★ Major |
| **修复难度** | ◆ 极低（改迭代次数） |
| **当前状态** | `initialize_nucleus()` 仅弛豫 50 步 × 1.0 fm/c = 50 fm/c |
| **论文要求** | Wang 2002: 至少 600 fm/c；Wang 2014: 至少 2000 fm/c 且检查虚假发射 |
| **影响** | 弛豫不充分的核在去除弹簧后无法稳定演化 |
| **修复方案** | 将弛豫步数增至至少 600（`initialize_nucleus`）或确保调用方总是使用 `initialize_and_relax`（已做 800 fm/c） |

### 差距 2.6: 缺少 w_r=0.8 fm 宽度校正

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★★★ Major |
| **修复难度** | ◆ 极低 |
| **当前状态** | `initialize_nucleus()` 中质子/中子采样的硬球半径无 w_r 校正（仅在 `_sample_grid_positions` 中有 `r_p - 0.8`） |
| **论文要求** | Wang 2014: 质子采样在 R_p - w_r 内，中子采样在 R_n - w_r 内，w_r = 0.8 fm |
| **影响** | 当 `initialize_nucleus()` 被直接调用（不经 `_sample_grid_positions`）时，缺少宽度校正导致核的 RMS 半径偏大 |
| **修复方案** | 确保所有初始化路径使用 `_sample_grid_positions()` 或直接应用 w_r 校正 |

### 差距 2.7: 缺少虚假发射检查

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★★★ Major |
| **修复难度** | ◆◆ 中等 |
| **当前状态** | 弛豫后无任何虚假粒子发射检查 |
| **论文要求** | Wang 2002: 拒绝有虚假粒子发射的核；Wang 2014 报告 IQ3a 在 t=2000 fm/c 时平均虚假发射约 1.1 (⁹²Zr) 到 2.6 (¹³²Sn) 个核子 |
| **影响** | 即使 BE 匹配，核可能在实际演化中缓慢解体 |
| **修复方案** | 弛豫后推进 500+ fm/c 无碰撞演化，检查是否有核子逃逸（距 CM > 15 fm），若有则拒绝该初始配置 |

### 差距 2.8: 缺少 RMF/Woods-Saxon 初始密度分布选项

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★ Moderate |
| **修复难度** | ◆◆◆ 较高 |
| **当前状态** | 仅有硬球初始化 |
| **论文要求** | Wang 2002: 使用 RMF 密度分布；Wang 2014 允许硬球但要求中子皮校正 |
| **影响** | 硬球初始化 + 弛豫对于中等质量核可以工作（18 个测试通过），但对重核（A>200）可能不充分 |
| **修复方案** | 可选地从 Woods-Saxon 或 Skyrme-HF 密度分布采样 |

### 差距 2.9: 质心移除在动量采样时重复

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★ Moderate |
| **修复难度** | ◆ 极低 |
| **当前状态** | `_fermi_momenta()` 采样后移除质心动量（第51行），`initialize_nucleus()` 弛豫期间又多次移除（第242行） |
| **论文要求** | 见 Wang 2014 初始化步骤；CM 校正应在初始化完成后做一次 |
| **影响** | 过度 CM 校正在弛豫期间可能人为压制合理的质心涨落 |

## 3. CoMD 相位空间约束

### 差距 3.1: 约束阈值使用 170 而非论文标准值

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★★★ Major |
| **修复难度** | ◆ 极低（改常数） |
| **当前状态** | `fermi_constraint_check()` 使用 `threshold=170.0` |
| **论文要求** | Wang 2002 和 Wang 2014 初始化阶段使用 255 fm·MeV/c |
| **影响** | 阈值过低意味着约束过松，许多违反 Pauli 原理的核子对未被修正 |
| **修复方案** | 将默认 threshold 改为 255（或区分初始化和传播阶段的不同阈值） |

### 差距 3.2: 仅对相同同位旋核子对施加约束

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★★★★ Critical |
| **修复难度** | ◆◆◆ 较高 |
| **当前状态** | `fermi_constraint_check()` 第395-396行: `if species[i] != species[j]: continue` |
| **论文要求** | CoMD/Papa 方法检查所有核子对的单体相位空间占据 `\bar f_i > 1`，不区分同位旋 |
| **影响** | np 对之间的 Pauli 违反未被修正，在混合体系中累积可能导致非物理的激发 |
| **修复方案** | 移除同位旋过滤，改为检查所有核子对或实现完整的单体占据检查 |

### 差距 3.3: 简化版约束——缺少多体弹性散射迭代

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★★★ Major |
| **修复难度** | ◆◆◆ 较高 |
| **当前状态** | `fermi_constraint_check()` 对每对违反的核子执行一次性弹性散射 |
| **论文要求** | 论文描述为"many-body elastic scattering to reduce occupation"，需检查散射后总能量是否在阈值内 |
| **影响** | 一次性散射可能不足以将占据降至 <1，且无能量守恒检查 |
| **修复方案** | 实现迭代散射：重新检查散射后的占据，若不满足则再次散射，同时检查能量变化 |

### 差距 3.4: 传播阶段约束频率不一致

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★ Moderate |
| **修复难度** | ◆ 极低 |
| **当前状态** | `propagate()` 中 `fermi_interval = max(1, int(round(5.0/dt)))`（无弹簧时每 5 fm/c 一次） |
| **论文要求** | 原始论文描述为"each time step"应用相位空间占据约束 |
| **影响** | 约束频率降低可能导致 Pauli 违反在两次检查之间累积 |

### 差距 3.5: 缺少单体占据 `\bar f_i` 计算

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★ Moderate |
| **修复难度** | ◆◆ 中等 |
| **当前状态** | 代码仅检测成对的 `dr*dp` 乘积，不计算核子 i 对所有其他核子的总 Wigner 占据 |
| **论文要求** | 原始 CoMD: 计算 `\bar f_i = Σ_j f_j(r_i,p_i)`，当 `\bar f_i > 1` 时触发多体散射 |
| **影响** | 一对核子可能各自都有高占据但彼此 dr*dp 很大而逃过检测 |

## 4. 波包宽度

### 差距 4.1: 所有核使用固定 σ_r=1.1 fm 而非 A 依赖公式

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★★★★ Critical |
| **修复难度** | ◆◆◆ 较高（涉及传播时动态宽度） |
| **当前状态** | `initialize_nucleus(sigma_r=1.1)` 默认值；所有核子共享同一固定宽度 |
| **论文要求** | Wang 2002 Eq.(18): `σ_r = σ_0 + σ_1 * A^(1/3)`；各 IQ 参数集有不同 (σ_0, σ_1) |
| **影响** | **这是 U+U (A=476) 完全解体的另一个根本原因。** σ_r=1.1 fm 对应 A≈66，对 A=476 系统来说宽度严重偏小。例如 IQ3a: σ_r(A=476) = 0.94 + 0.020×476^(1/3) ≈ 1.15 fm，虽有差距但不太大；IQ2: σ_r(A=476) = 0.88 + 0.090×476^(1/3) ≈ 1.83 fm——固定 1.1 fm 严重低估了大系统的宽度 |
| **修复方案** | 1) `initialize_nucleus` 根据 A 自动计算 σ_r；2) 传播时根据碎片大小动态调整宽度 |

### 差距 4.2: 弹靶独立宽度未实现

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★★★ Major |
| **修复难度** | ◆◆ 中等 |
| **当前状态** | 所有核子使用同一 `nucleus.sigma_r` |
| **论文要求** | Wang 2014: 弹核和靶核各用自己的 A^(1/3) 相关宽度初始化；接触后过渡到系统相关宽度 |
| **影响** | 非对称反应中（如 Kr+Ni, A1=78, A2=58），两边应使用不同宽度 |
| **修复方案** | 支持 `GaussianPacket` 独立 `sigma_r` 属性；传播时使用局部密度确定有效 A |

### 差距 4.3: σ_r·σ_p = ħ/2 关系在能量计算中不一致

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★★ Moderate |
| **修复难度** | ◆◆ 中等 |
| **当前状态** | `density()` 和 `centroid_densities()` 使用 `sigma_r` 计算空间密度，但 Pauli 阻塞中使用 `sigma_p = HBAR_C/(2*sigma_r)` |
| **论文要求** | `σ_r·σ_p = ħ/2` 应全局满足 |
| **影响** | 密度计算和 Pauli 阻塞使用一致的宽度关系，但 `surface_pair_energy` 等使用 `2σ_r` 范围，需要验证一致性 |

## 5. Pauli 阻塞

### 差距 5.1: PB(W*) 未被正确实现——仅有宽度展宽近似

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★★★ Major |
| **修复难度** | ◆◆◆◆ 极高 |
| **当前状态** | `pauli_blocking_probability_v2` 仅将 Wigner 核宽度乘以 1.35（`width_scale=1.35`），标记为"Chen-2024-inspired" |
| **论文要求** | Chen 2024 PB(W*): 对每个邻居 j，将动量占据替换为 N 个抽样动量状态的指数和平均（式 6-7），报告方差降低 70% |
| **影响** | 真正的 PB(W*) 通过动量状态采样抑制统计涨落，简单展宽无法达到同等效果。对 U+U 计算中泡利阻塞的可靠性有显著影响 |
| **修复方案** | 实现 Chen 2024 Eq.(6)-(7): 对每个邻居采样 N 个动量方向（通常 N=20-50），计算 c_j(p'_i) = (1/N)Σ_λ exp[-(p'_i-P_{j,λ})²/(2σ_p²)] |

### 差距 5.2: 泡利阻塞中的费米底板启发式不在论文中

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★★ Moderate |
| **修复难度** | ◆ 极低（移除或文档化） |
| **当前状态** | `_occupation_wigner()` 第94-99行: 引入 `fermi_floor`（0.75 当 p < p_F，否则指数衰减），将占据钳位在 `max(occupation, fermi_floor)` |
| **论文要求** | 论文中的 Pauli 阻塞不包含费米底板；占据仅从 Wigner 求和计算 |
| **影响** | 费米底板可能遮掩低密度区域的泡利违反，导致碰撞接受率偏高 |
| **修复方案** | 移除费米底板或显式标记为工程优化并追溯到文献依据 |

### 差距 5.3: 泡利阻塞缺少硬球重叠替代方案（Chen 2024 Eq.2）

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★ Moderate |
| **修复难度** | ◆◆ 中等 |
| **当前状态** | 仅实现 Wigner 核占据（Chen 2024 Eq.1） |
| **论文要求** | Chen 2024 同时提供硬球重叠方案（Eq.2）作为对照 |
| **影响** | 缺少对照方法，无法区分 Wigner 核和硬球方案的差异 |

### 差距 5.4: 碰撞中的泡利阻塞使用预计算的密度而非实时密度

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★★★ Major |
| **修复难度** | ◆ 极低 |
| **当前状态** | `_pauli_blocking_probability_fast()` 使用 `centroid_densities()` 返回的预计算密度 `rho_n, rho_p` |
| **论文要求** | 泡利阻塞应基于碰撞时刻的即时密度 |
| **影响** | 在碰撞步骤中，前序碰撞可能已改变核子位置，但使用的密度仍是步骤开始时的值。对于多碰撞步骤，误差累积 |

## 6. 退激发

### 差距 6.1: Weisskopf-Ewing 蒸发宽度计算过于简化

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★★★ Major |
| **修复难度** | ◆◆◆ 较高 |
| **当前状态** | `_evaporation_width()` 使用 A^(2/3)·ε·exp(2√(aE)) 近似 |
| **论文要求** | Weisskopf-Ewing 积分: Γ_j ∝ ∫ σ_j^inv(ε)·ρ_d(E*-B_j-ε)·ε dε |
| **影响** | 简化公式在每个蒸发步骤丢失了逆截面和能级密度的能量依赖。对高激发碎片（E* > 50 MeV），误差显著 |
| **修复方案** | 实现完整的 Weisskopf-Ewing 数值积分或使用已验证的参数化 |

### 差距 6.2: γ 道竞争使用启发式而非物理宽度

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★★ Major |
| **修复难度** | ◆◆ 中等 |
| **当前状态** | `weisskopf_evaporation_multi()` 中 `gamma_width = max(0.1*gamma_reference, 1e-12)` |
| **论文要求** | HIVAP 使用 GDR 巨偶极共振参数计算 Γ_γ(E1) |
| **影响** | γ 宽度被设为中子宽度的 10%，对于质子丰中子核（S_n 很大时）可能严重低估 γ 竞争 |

### 差距 6.3: 裂变竞争使用简化液滴模型而非 Sierk/Barrier 表

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★★ Major |
| **修复难度** | ◆◆◆ 较高 |
| **当前状态** | `fission_barrier()` 使用液滴模型 + 简单壳修正 |
| **论文要求** | HIVAP 使用 Sierk 转动液滴模型势垒或实验裂变势垒表 |
| **影响** | 对于 Z > 90 的超铀核，液滴裂变势垒与实验值的差异可达 2-3 MeV，显著影响残余截面 |
| **修复方案** | 集成已知的裂变势垒参数化（如 Möller 1995 或 RIPL-3） |

### 差距 6.4: 多步蒸发能量扣除过于简化

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★ Moderate |
| **修复难度** | ◆ 极低 |
| **当前状态** | `_channel_energy_cost()` 扣除 S_n + 3T（动能），一次性扣除 |
| **论文要求** | 标准统计模型在每一步扣除分离能 + 平均动能（通常为 2T），且使用更新的能级密度参数 |
| **影响** | 多个蒸发步后 E* 累积误差约 10-20% |

### 差距 6.5: 缺少与 HIVAP/GEMINI 外部耦合接口

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★ Moderate |
| **修复难度** | ◆◆ 中等 |
| **当前状态** | 仅有内部蒸发/裂变实现，无外部耦合 |
| **论文要求** | Zhao 2016 的 U+U 工作流: ImQMD→HIVAP 耦合；Yao 2017: ImQMD→GEMINI 耦合 |
| **影响** | 无法复现 Zhao 2016 的确切结果（HIVAP 实现可能与内建简化版不同） |
| **修复方案** | 提供接口将 (Z, A, E*) 输出为标准格式供外部代码读取 |

## 7. 其他差距

### 差距 7.1: 缺少碰撞几何中 In-Medium 因子的 η 能量依赖性

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★★★ Major |
| **修复难度** | ◆◆ 中等 |
| **当前状态** | `in_medium_factor()` 使用固定 `η=0.2`（Zhang 2012 E_beam=50A MeV 的值） |
| **论文要求** | Zhang 2012: `ξ(E_beam)` 随入射能量变化；Chen 2024: `η(√s)` 允许能量依赖 |
| **影响** | 对于 U+U E_beam=7 MeV/A，固定 η=0.2 可能高估介质抑制效应（低能时应更低） |

### 差距 7.2: 缺少 Wei 2014 LCP 表面凝聚模块

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★★ Major |
| **修复难度** | ◆◆◆ 较高 |
| **当前状态** | `fragments.py` 中 `coalescence_light()` 使用简单的相位空间凝聚（r_cut=2.4, p_cut=180），不同于 Wei 2014 的表面发射机制 |
| **论文要求** | Wei-Wang-Ou 2014: 表面凝聚使用核心+表面厚度模型，领头核子通过表面发射 + 候选核子通过 Jacobi 坐标条件加入，优先顺序 ⁴He > ³He > t > d，需检查 Coulomb 势垒穿透 |
| **影响** | LCP 产额计算基于错误模型；对 spallation 应用有严重影响；对融合/MNT 影响较小 |

### 差距 7.3: 缺少反应截面（碰撞参数积分）模块

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★★ Major |
| **修复难度** | ◆◆ 中等 |
| **当前状态** | 无碰撞参数积分或事件统计模块 |
| **论文要求** | Wang 2014 Eq.(10) 融合截面；Zhao 2016 Eq.(3) 碎片截面积分；Wei 2014 Eqs.(14-15) 双微分能谱 |
| **影响** | 无法直接从代码产出可与实验对比的截面数据 |
| **修复方案** | 实现事件循环 + 碰撞参数网格 + 截面累计模块 |

### 差距 7.4: O(N²) 密度求值在传播时无优化

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★★ Major |
| **修复难度** | ◆◆ 中等 |
| **当前状态** | `_centroid_density_force()` 对所有 (i,j) 对做 O(N²) 计算 |
| **论文要求** | 无直接要求，但实际 ImQMD 代码（C++/Fortran）使用网格截断或 neighbor list |
| **影响** | 对 A=476 系统，每 RK4 步需计算 476² ≈ 226K 对；传播 1000 步 = 226M 对计算，性能严重下降 |
| **修复方案** | 已存在 `GridEDF` 网格方案（O(N·n_cells)）——确保传播默认使用 GridEDF |

### 差距 7.5: 未实现形变核初始化（β₂, β₄）

| 属性 | 值 |
|------|-----|
| **严重程度** | ★★ Moderate |

| **论文要求** | Zhao 2016 U+U: ²³⁸U 使用 β₂=0.215, β₄=0.093 形变 + 随机取向 |
| **影响** | U+U 计算需要形变初始化以正确模拟核形状对熔合和转移反应的影响 |
